# research-report-reader

**投研报告精读助手** — 一个 WorkBuddy / CodeBuddy skill，用于系统化阅读、提炼和交叉比对投资研究报告（券商研报、行业报告、宏观策略报告），并对英文报告产出逐段中文全文翻译。

## 它解决什么问题

把一份或多份 PDF 研报丢进来，它会输出三样东西：

1. **逐篇结构化摘要** — 核心观点、关键假设、投资建议、风险提示、一句话判断
2. **跨报告交叉比对** — 一致性信号、矛盾点、预期差地图（多篇时）
3. **英文报告中文全文翻译** — 逐段逐句，还原标题层级、表格、列表、脚注

最后挑出 1–2 篇最值得精读的，并针对报告类型（宏观框架 / 微观调研 / 行业公司）给出差异化的精读方法。

## 触发场景

- 上传 PDF 研报并要求阅读、分析、总结、精读、提炼要点
- "帮我读报告" / "分析这几篇研报" / "研报精读" / "核心观点是什么"
- "这些报告值得读吗" / "帮我看看这些 PDF"

## 方法论

**三层阅读法**（逐篇）

| 层次 | 目标 | 看什么 |
|---|---|---|
| 第一层 | 定位核心逻辑 | 标题、摘要、投资建议、目标价 —— 是行业反转、估值修复、业绩超预期还是风险预警 |
| 第二层 | 拆解假设与证据 | 关键假设、核心图表结论、风险提示（合规要求写下的才是分析师真正怕的） |
| 第三层 | 评估调研深度 | 有无一手数据、具名客户/供应商、渠道数据，财务假设是否激进 |

**交叉比对**（多篇）：多个独立来源同向 → 信号更可靠；报告间逻辑冲突处 → 往往尚未被定价。

**预期差优先**：研报的价值不在信息量，而在揭示"市场共识与真实情况之间的缝隙"。

## 输出物

```
投研报告精读分析_[日期].md      # 分析摘要（主交付物）
[报告简称]_中文翻译.md          # 每篇英文报告一份
```

## 安装

把本目录复制到 WorkBuddy 的 skills 目录：

```bash
# 用户级（所有项目可用）
cp -r research-report-reader ~/.workbuddy/skills/

# 项目级（仅当前工作区）
cp -r research-report-reader <workspace>/.workbuddy/skills/
```

依赖 `workbuddy-pdf` skill 做 PDF 文本与图像核对（本机无 `pdftotext`）。
